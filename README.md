# Analysis and Design of Algorithms (ADA) Lab

This repository contains **Analysis and Design of Algorithms (ADA) Lab programs** for **4th Semester Computer Science and Engineering (CSE)** under the **VTU 2022 Scheme**.

The programs are implemented in **C** and cover important algorithms related to graph theory, sorting, dynamic programming, greedy techniques, and backtracking.

## 📚 Course Details

- **University:** Visvesvaraya Technological University (VTU)
- **Branch:** Computer Science and Engineering (CSE)
- **Semester:** 4th Semester
- **Scheme:** 2022 Scheme
- **Subject:** Analysis and Design of Algorithms (ADA)
- **Programming Language:** C

## 🛠️ Requirements

- GCC compiler or another C compiler
- A terminal or command prompt
- Any C-compatible code editor, such as Visual Studio Code

## ▶️ How to Compile and Run

1. Clone the repository:

   ```bash
   git clone https://github.com/Suhas810/analysis-and-design-of-algorithms-lab.git
   ```

2. Navigate to the repository folder:

   ```bash
   cd analysis-and-design-of-algorithms-lab
   ```

3. Compile a C program:

   ```bash
   gcc filename.c -o output
   ```

4. Run the executable:

   **Linux / macOS:**
   ```bash
   ./output
   ```

   **Windows:**
   ```bash
   output.exe
   ```

   Replace `filename.c` with the name of the program you want to execute.

## 🎯 Learning Objectives

- Understand fundamental algorithm design techniques.
- Implement graph algorithms and shortest-path algorithms.
- Learn greedy algorithms and dynamic programming.
- Practice sorting and searching techniques.
- Understand recursion and backtracking.
- Analyze algorithm efficiency and computational complexity.
